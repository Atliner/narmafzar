# NEON CAD — نرم‌افزار طراحی و آماده‌سازی تابلو نئون (v2)

> **راهنمای کامل فارسی:** داخل نرم‌افزار دکمهٔ **HELP / راهنما** (یا کلید **F1**) را بزنید — در اولین ورود هم خودکار باز می‌شود. نسخهٔ متنی: [docs/GUIDE-fa.md](docs/GUIDE-fa.md)

یک اپلیکیشن وب کامل برای طراحی تابلو نئون: از طرح دیجیتال تا فایل آماده ساخت.
به‌صورت **یک Cloudflare Worker تک‌فایلی** (`worker.js`) ارائه می‌شود — کل HTML/CSS/JavaScript داخل همان فایل است و **تمام پردازش‌های هندسی در سمت مرورگر** انجام می‌شود (بدون سرور جانبی، بدون وابستگی به CDN).

> طراحی معماری، ساختار داده و الگوریتم‌ها پیش از کدنویسی در [docs/DESIGN.md](docs/DESIGN.md) مستند شده است.

### نکتهٔ کلیدی: اصلاح هندسی، نه گرد کردن عدد

اگر طول مسیر `83.2 cm` باشد، نرم‌افزار عدد را به `85 cm` گرد **نمی‌کند**؛ بلکه **هندسه را واقعاً اصلاح می‌کند**:

- انتهای آزاد → تغییر مقیاس یکنواخت حول مرکز ثقل (شکل حفظ می‌شود)
- انتهای قفل (اتصال به زنجیره) → تغییر ضریب عمودی رأس‌های داخلی نسبت به وتر با جست‌وجوی دو‌دودویی تا طول واقعی دقیقاً `85 cm` شود

طول هدف = `ceil(L / 2.5) × 2.5` (همیشه به بالا — هیچ تکه‌ای کوتاه‌تر از اندازهٔ لازم بریده نمی‌شود).
در نتیجه **همهٔ نقاط START و END واقعاً روی Cutting Pointهای فیزیکی 2.5cm نئون می‌نشینند.**

## تبدیل عکس به نئون + متن نئونی + فایل برش‌دهنده (v2)

### TRACE IMAGE v2 — عکس به نئون
1. روی **TRACE IMAGE** بزنید و هر عکسی را آپلود کنید (لوگو، خط‌نویس، متن، طرح).
2. **حالت ترسیم** را انتخاب کنید:
   - **Auto (پیش‌فرض):** ضخامت مؤثر خطوط از روی مساحت/محیط کانتورها برآورد می‌شود؛ شکل‌های توپُر (لوگوی پُر، فونت فت) خودکار به Outline می‌روند و خط‌نویس نازک به Centerline — دیگر «تشخیص نمی‌داد» ندارید.
   - **Centerline (تک‌خط):** فیلتر میانه → باینری‌سازی (آستانهٔ خودکار Otsu) → حذف نویز → بستن مورفولوژیک ترک‌ها → اسکلت‌سازی Zhang-Suen → هرس شاخه‌ها → **برگرداندن نوک خطوط** → ساده‌سازی RDP → منحنی نرم Bezier.
   - **Outline (دو خطی):** استخراج کانتور با **marching squares** (دقت زیرپیکسل) → هر دو لبهٔ هر خط → نمای دولاین.
3. پیش‌نمایش دقیقاً همان نتیجهٔ نهایی است (WYSIWYG)؛ کیفیت ترسیم تا 1600px قابل انتخاب است.
4. همهٔ طول‌ها به‌صورت **هندسی** به گام برش (پیش‌فرض 2.5cm) اصلاح می‌شوند (START/END روی Cut Point واقعی).
5. با دکمهٔ **CHANNEL** (سمت چپ) دو خط موازی اطراف هر مسیر را ببینید — عرض کانال در PROPERTIES → *Cutting Channel Width*.
6. **CUT DXF** یا **CUT SVG** را دانلود کنید — شامل **طرح دوبل** برای برش‌دهنده (CNC / روتر / لیزر).

### NEON TEXT — متن نئونی واقعی (فارسی/انگلیسی)
ابزار **Text** (یا دکمهٔ **NEON TEXT**) → متن را بنویسید، فونت/اندازه/Bold/Italic/فاصله را بدهید → **Create neon text**.
متن به مسیر واقعی نئون تبدیل می‌شود (در جدول برش، در خروجی‌ها، قابل ویرایش). دو حالت:
- **Centerline:** یک ریسه روی محور خطوط حروف.
- **Outline — دو خطی:** ریسه از دو طرف هر خط حروف (نمای دولاین مانند تابلوهای حرفه‌ای).

اگر فقط برچسب چاپی می‌خواهید (نئون نیست)، تیک *note/label only* را بزنید.

### DOUBLE LINE — دولاین‌کردن هر طرح
هر مسیری (دست‌کشیده، تریس‌شده، شکل، متن) را انتخاب کنید و **Double Line** را بزنید: مسیر به دو خط نئون موازی با فاصلهٔ دلخواه (PROPERTIES → *Double-line gap*) تبدیل می‌شود.

### ابزارهای مشابه CorelDRAW
اشکال هندسی (مستطیل/بیضی/چندضلعی/ستاره/مارپیچ)، دستگیره‌های Transform (گوشه = مقیاس متناسب، کنار = کشش، دایرهٔ زرد = چرخش)، پنل TRANSFORM عددی، Flip H/V، Align & Distribute، To Front/Back، **Boolean (Weld/Trim/Intersect)**، Duplicate/Copy/Paste (Ctrl+D/C/V/A)، رنگ نئون هر مسیر، تب **OBJECTS** (نمایش/مخفی/قفل/حذف — مسیر مخفی از جدول برش و خروجی‌ها حذف می‌شود)، Zoom In/Out/Fit (کلید F) و خروجی **EPS** (مخصوص باز شدن در CorelDRAW/Illustrator).

> این برنامه یک CAD تخصصی ساخت نئون است؛ ابزارهای اصلی CorelDRAW که برای طراحی تابلو لازم است را دارد (ویرایش بیت‌مپ/چندصفحه‌ای/CMYK ندارد).

## استقرار روی Cloudflare Worker + اتصال خودکار GitHub

### ۱. ساخت Worker از روی مخزن GitHub

1. به [Cloudflare Dashboard](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Import a repository** بروید.
2. مخزن GitHub این پروژه (`narmafzar`) را انتخاب کنید (در صورت نیاز ابتدا GitHub را به Cloudflare وصل کنید — *Workers Builds*).
3. Cloudflare فایل [`wrangler.toml`](wrangler.toml) را به‌صورت خودکار تشخیص می‌دهد:
   - **Framework preset:** None
   - **Build command:** *(خالی — نیاز به build نیست)*
   - **Deploy command:** `npx wrangler deploy`
4. روی **Save and Deploy** بزنید. آدرس عمومی شما `https://narmafzar.<account>.workers.dev` خواهد بود.

### ۲. استقرار خودکار با هر تغییر

از این پس **هر push به مخزن، به‌صورت خودکار در Cloudflare مستقر می‌شود**؛ یعنی تغییرات مستقیماً از GitHub داخل Cloudflare ذخیره و انتشار می‌یابند. وضعیت هر استقرار در تب **Deployments** همان پروژهٔ Worker دیده می‌شود.

### ۳. اجرای محلی با Wrangler (اختیاری)

```bash
npm install
npx wrangler dev      # اجرای محلی Worker
npm run deploy        # استقرار دستی
```
